# Generated regression fixtures

These five generated room paintings are comparison inputs for the current browser tests, not source/reference photographs. They are kept outside `public/` and are not included in the deployed website.

- `pixi-structural-background-v2.png`: checks that the integrated room retains the repaired desk and wall geometry.
- `pixi-desk-wall-composite.png`: checks the desk's wall-side support.
- `summer-room-v7.webp`: checks fixed window, door, monitor and photo-frame registration.
- `summer-room-v8.webp`: checks the accepted painted keyboard and wrist rest.
- `summer-room-v10.webp`: checks that the half-size stress-ball repair leaves the rest of the painting unchanged.

The current scene loads `public/art/summer-room-v11.svg`. Do not move these test fixtures into `public/`.
